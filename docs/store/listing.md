## 스토어 등록정보 탭

### 이름

매니페스트에서 자동으로 가져온다: `체험단 리뷰 제거기` (1.0.0 까지는 `체험단 리뷰 제거기 for 쿠팡`)

### 요약

매니페스트의 `description` 에서 자동으로 가져온다.

```
쿠팡과 무신사 리뷰에서 체험단 리뷰를 찾아 숨기고, 체험단을 뺀 평점을 보여 줍니다. 숨긴 리뷰는 언제든 다시 볼 수 있습니다.
```

### 설명

```
쿠팡과 무신사에서 리뷰를 볼 때 체험단 리뷰가 얼마나 섞여 있는지 바로 보여 줍니다.

하는 일
- 체험단 제공 리뷰에 표시를 붙입니다
- 버튼 하나로 체험단 리뷰를 숨기고, 다시 누르면 다시 보여 줍니다
- 체험단 리뷰를 뺀 평점을 계산해 원래 평균과 나란히 보여 줍니다
- 지금까지 본 리뷰 중 체험단 리뷰의 비중을 알려 줍니다

판별 기준
쇼핑몰이 리뷰에 직접 붙이는 안내 문구가 있는 리뷰만 체험단 리뷰로 봅니다. 추측으로 판정하지 않습니다.
- 쿠팡: "쿠팡체험단 이벤트로 상품을 무료로 제공받아 작성한 구매 후기"
- 무신사: "이 후기는 제품을 무상으로 제공받아 직접 사용해 본 후 작성되었습니다"

동작하는 곳
- 쿠팡 상품 페이지
- 무신사 상품 페이지와 후기 전체보기
무신사에서 체험단 조건을 직접 골라 체험단 후기만 모아 볼 때는 숨기지 않습니다.

숫자의 범위
평점과 비중은 사용자가 화면에서 실제로 본 리뷰만으로 계산합니다. 상품 전체 리뷰의 통계가 아닙니다.

익명 사용 통계(선택)
설치 직후 화면이나 확장 패널에서 통계 전송을 켠 경우에만 익명 사용 통계를 보냅니다. 배너가 뜬 횟수, 체험단 비중 같은 숫자, 버튼을 눌렀는지, 리뷰 정렬 방식, 쿠팡과 무신사 중 어디에서 썼는지, 확장 화면을 열었는지와 머문 시간, 오류 종류가 포함됩니다. 리뷰 내용, 상품 이름과 주소, 쇼핑몰 계정 정보는 보내지 않습니다. 상품 번호는 되돌릴 수 없는 값으로 바꿔 보내므로 어떤 상품을 봤는지는 만든 사람도 알 수 없습니다. 동의하지 않아도 모든 기능을 쓸 수 있고, 패널에서 언제든 끌 수 있습니다.

이 확장은 쿠팡, 무신사와 관계가 없는 개인이 만들었습니다.
```

## 개인 정보 보호 탭

### 단일 목적

```
쿠팡과 무신사 상품 페이지의 리뷰에서 체험단 제공 리뷰를 표시하고 숨기며, 체험단 리뷰를 제외한 평점을 보여 준다.
```

### 권한 사유

| 권한 | 사유 |
|---|---|
| `storage` | 익명 기기 번호, 통계 전송 동의 여부, 탭별 리뷰 요약을 브라우저 안에 저장한다. |
| `sidePanel` | 체험단 비중과 체험단 제외 평점의 상세를 브라우저 사이드 패널에 표시한다. |
| 호스트 권한 (콘텐츠 스크립트: `https://www.coupang.com/vp/products/*`, `https://www.musinsa.com/products/*`, `https://www.musinsa.com/review/goods/*`) | 쿠팡 상품 페이지, 무신사 상품 페이지와 후기 전체보기의 리뷰 영역을 읽어 체험단 리뷰를 표시하고 숨기며 배너를 삽입한다. 다른 사이트나 두 쇼핑몰의 다른 페이지에서는 동작하지 않는다. 1.1.0 에서 무신사의 두 주소를 더했다. |

### 원격 코드

사용하지 않음. 모든 코드는 패키지 안에 들어 있다.

### 데이터 사용

수집한다고 체크할 항목:

| 항목 | 체크 | 이유 |
|---|---|---|
| 사용자 활동 | 예 | 숨기기 버튼, 패널, 장바구니와 구매 버튼을 눌렀는지를 익명 통계로 보낸다(동의한 경우만). 필터가 구매 판단에 도움이 됐는지 측정하기 위해서다 |
| 웹 기록 | 예 | 쿠팡과 무신사의 상품 페이지를 본 사실과 시각, 어느 쇼핑몰인지가 익명 통계에 포함된다. 어떤 상품인지는 되돌릴 수 없는 값으로만 남지만 보수적으로 체크한다 |
| 개인 식별 정보 | 아니오 | 이름, 이메일, 주소를 다루지 않는다 |
| 건강 정보 | 아니오 | |
| 금융 및 결제 정보 | 아니오 | 결제 정보를 읽지 않는다. 구매 버튼을 눌렀는지만 본다 |
| 인증 정보 | 아니오 | |
| 개인 통신 | 아니오 | |
| 위치 | 아니오 | |
| 웹사이트 콘텐츠 | 아니오 | 리뷰 내용은 브라우저 안에서만 읽고 어디로도 보내지 않는다 |

인증 세 가지는 모두 체크한다.

- 승인된 사용 사례 외의 용도로 사용자 데이터를 제3자에게 판매하거나 이전하지 않는다
- 항목의 단일 목적과 관련 없는 용도로 사용자 데이터를 사용하거나 이전하지 않는다
- 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 이전하지 않는다
