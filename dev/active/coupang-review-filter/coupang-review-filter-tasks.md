- 이름은 `체험단 리뷰 제거기` 로 바꾼다(쇼핑몰 이름을 뺀다)

제시한 설계안(사용자가 "내일 진행" 이라고 함, 아직 승인 전):
- 대상 페이지: `musinsa.com/products/*`, `musinsa.com/review/goods/*`
- 판별: 후기 카드 안의 문구 `이 후기는 제품을 무상으로 제공받아 직접 사용해 본 후 작성되었습니다.` (감싸는 요소 class 는 `ExperienceLabelInfo__Wrapper...`). 후기 카드는 `data-content-id=<후기 번호>` 를 가진 요소(class `review-list-item__Container...`)
- 무신사의 `체험단` 탭(`data-filter-value=체험단`)이 선택된 동안에는 숨기지 않고 배너로 알린다
- 코드 구조: 쿠팡 전용 부분(selectors, parser, sort, purchase)을 쇼핑몰별 부품으로 떼고 쿠팡용과 무신사용을 둔다. 쿠팡 동작은 바꾸지 않는다
- 통계: 모든 이벤트에 `site`(coupang, musinsa). product_key 는 쇼핑몰끼리 겹치지 않게
- 글자 수정: 이름, 스토어 요약과 설명, 온보딩, 사이드 패널, 처리방침, 랜딩, 권한 사유, 스크린샷 한 장 추가
